# Security Policy

## Supported Versions

This project currently supports the latest `main` branch.

## Reporting a Vulnerability

Please open a private security advisory on GitHub for this repository.
If private advisory is unavailable, open an issue requesting a private contact path.

Do not post exploit details publicly before a fix is available.

## Scope

Security concerns in scope:
- Install/update/uninstall script safety
- Secrets exposure in repo contents
- Unsafe default permissions or command execution in templates
- Path traversal or uncontrolled file writes in scripts
